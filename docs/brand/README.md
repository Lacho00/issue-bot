# Brand

The mascot is a small robot with a bug on its antenna: it chats with you, catches the bug and
fixes it.

| File | Use |
|---|---|
| `logo.svg`, `logo-640.png` | Avatar with background: Telegram bot, GitHub |
| `logo-small.svg` | 48 px and below: simpler bug, thicker strokes |
| `logo-mark.svg` | No background, for the README on light and dark themes |
| `social-preview.png` | GitHub social preview, 1280×640 |
| `moods/*.svg` | Expressions: neutral, thinking, working, happy, worried |

The report header draws the mascot inline from `src/mascot.js`: happy when every issue is fixed
or is not a code issue, worried when one is still pending, neutral otherwise.

Colours: navy `#0F172A`, white `#F8FAFC`, amber `#F59E0B`, green `#22C55E`, red `#EF4444`,
slate `#94A3B8`. The banner uses Space Grotesk Bold and Inter (SIL Open Font License).
